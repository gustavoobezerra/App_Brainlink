# FDA — NEBA System e precedentes

> Referência internacional. Não vincula no Brasil, mas estabelece o padrão do que
> é preciso demonstrar para afirmar algo — e do que nunca foi autorizado afirmar.

## NEBA System (2013)

Autorizado pelo FDA em **15 de julho de 2013**, por classificação *de novo*
(K112711). Foi o primeiro dispositivo baseado em biomarcador cerebral autorizado
para qualquer condição psiquiátrica nos Estados Unidos.

| Parâmetro | Valor |
| --- | --- |
| Medida | Razão theta/beta do EEG |
| Eletrodo | Canal único, posição **Cz** (vértice) |
| Duração da sessão | 15 a 20 minutos |
| Faixa etária | **6 a 17 anos** |
| Classe | II, código de produto NCG |
| Uso autorizado | **Apoio** à avaliação clínica |
| Sensibilidade (6–11 anos) | 79% |
| Especificidade (6–11 anos) | 97% |
| Acurácia combinada com avaliação clínica | De 61% para 88% |

## O que o FDA nunca autorizou

A indicação de uso é explícita:

> O NEBA deve ser usado por um clínico apenas como suporte confirmatório de uma
> avaliação clínica completa, ou como apoio à decisão de prosseguir com testagem
> adicional após avaliação clínica. **O dispositivo NÃO deve ser usado
> isoladamente na avaliação ou diagnóstico de TDAH.**

O FDA jamais autorizou o TBR — nem o NEBA — como ferramenta diagnóstica autônoma.
A autorização é estritamente como *aid*, em conjunto com avaliação comportamental
estruturada.

## Duas ressalvas que mudam o peso do precedente

**1. Operadoras de saúde tratam como investigacional.** Políticas médicas de
planos de saúde nos EUA seguem classificando a avaliação isolada de TBR como
"investigacional e/ou não comprovada". Mesmo o dispositivo autorizado não é
considerado prática médica padrão pela maior parte do sistema de saúde.

**2. A AAN recomenda contra.** Três anos após a autorização, a American Academy
of Neurology emitiu [[practice-advisory-aan]] recomendando formalmente não usar
TBR para confirmar diagnóstico, citando risco de dano por falso-positivo.

O precedente regulatório, portanto, é mais frágil do que a data de 2013 sugere:
autorizado, restrito a apoio, não coberto pela maioria dos planos, e
desaconselhado pela sociedade de neurologia.

## Aplicação direta a este projeto

**O eletrodo é diferente.** O NEBA mede em Cz; o BrainLink mede em Fp1. Nenhuma
alegação de equivalência é sustentável. Ver [[limitacoes-fp1]].

**A moldura de linguagem é o que se deve copiar.** O que o NEBA faz de exemplar,
e que este projeto deve imitar, é a disciplina de nunca se apresentar como
resultado. Ver [[linguagem-permitida]].

## Outros precedentes relevantes

**QbTest** — CPT com rastreamento de movimento, autorizado pelo FDA como *aid to
clinical assessment*. Mesmo padrão: medida objetiva como insumo, nunca veredito.
Ver [[testes-cpt]].

**EndeavorRx** — videogame terapêutico por prescrição, autorizado para crianças
de 8 a 12 anos com TDAH desatento ou combinado. Ensaio pivotal STARS-ADHD,
N = 348, randomizado, cego e controlado, com desfecho no TOVA. É a régua do que
significa "demonstrar eficácia" nesse domínio — e o contraste com a base de
evidência do neurofeedback é instrutivo. Ver [[neurofeedback-tbr]].
